# Campus Food Order System

## 1. What is this project about?
This project is a Java-based application designed to manage food orders on a university campus. It allows students to place orders, calculates delivery fees automatically, and sends notifications via different channels like Email, SMS, or Push notifications.

## 2. Which design patterns are used?
To make the code professional and maintainable, two patterns were implemented:
* **Singleton Pattern:** Used in the `AppConfig` class to store university settings (name, fee) in a single, central location.
* **Factory Pattern:** Used in the `NotificationFactory` class to create different notification types dynamically based on user input.

## 3. How to Compile the project?
To compile all the Java files in the project, open your terminal and run:
```bash
javac src/*.java

```

## 4. How to Run the project?

After compiling, run the main application with this command:

```bash
java -cp src Main

```

## 5. What output should be expected?

The program will display the order details, the delivery fee retrieved from the config, and a confirmation message from the selected notification service.
